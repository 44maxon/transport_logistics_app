# Мобильное приложение «Транспортная логистика»

Учебный прототип на Python и Kivy для Android. Приложение строит порядок посещения точек доставки для одного автомобиля.

## Возможности
- добавление до 8 точек доставки;
- ввод координат, веса груза и временного окна каждой точки;
- настройка грузоподъёмности, средней скорости, времени выезда и тарифов;
- проверка суммарной загрузки автомобиля;
- проверка временных окон, ожидание при раннем прибытии;
- расчёт расстояния, времени завершения и условной стоимости;
- поиск лучшего допустимого порядка посещения точек полным перебором.

## Запуск на компьютере
Python 3.10 или новее:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Сборка APK для Android (Linux)
Для сборки используется Buildozer. Установите системные зависимости Buildozer и Android SDK/NDK согласно официальной инструкции Kivy/Buildozer, затем:

```bash
python -m pip install buildozer
buildozer init
```

В `buildozer.spec` задайте:

```ini
 title = Транспортная логистика
 package.name = transportlogistics
 package.domain = org.student.practice
 source.include_exts = py,png,jpg,kv,atlas
 requirements = python3,kivy==2.3.1
 orientation = portrait
 android.archs = arm64-v8a
```

Сборка:

```bash
buildozer -v android debug
```

APK появится в папке `bin/`.

## Модель и ограничения
- Координаты точек задаются в условных километрах в единой плоской системе координат.
- Расстояние между двумя точками считается по формуле Евклидова расстояния.
- Скорость считается постоянной; пробки и дорожные ограничения не моделируются.
- На каждую доставку заложено условное обслуживание 10 минут.
- Все доставки перевозятся одним автомобилем; проверяется суммарный вес.
- Для небольшого числа точек (до 8) полный перебор находит глобально лучший допустимый порядок по времени, расстоянию или стоимости. При увеличении числа точек следует перейти к эвристикам/метаэвристикам или алгоритмам маршрутизации на графе дорог.

Это учебная расчётная модель, а не навигатор: адреса не геокодируются, реальные дороги и пробки не используются.
